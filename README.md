# apple-iic-lcd-monitor-mount
Apple IIc LCD Monitor Mount

This mount's arm is designed to attach to the back of a 12" LCD monitor via the VESA bracket.

The base is designed to fit on top of an Apple IIc.

The monitor I designed it against is the "Eyoyo CCTV Monitor 12 Inch Small Computer Monitors" but will probably work ok with most monitors that could be described as a "12in Mini Security Monitor".

## Instructions

To assemble this LCD Mount you will need:
(1) Arm
(1) Base
(2) M2.5 nuts, metal preferred
(2) M2.5 15mm bolts
(4) M4 screws for the VESA mount, though this size varies depending on model. My screen used (2) 16mm M4 and (2) 8mm M4 bolts. The lower screw holes weren't as deep as the upper ones for whatever reason.
